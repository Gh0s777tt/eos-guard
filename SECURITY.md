# Security policy

**This repository is archived and receives no security fixes.**

Its functionality lives in [`eos-control`](https://gitlab.com/e-os/eos-control). Report anything
concerning the shipped behaviour there, or through the E-OS policy:
<https://gitlab.com/e-os/e-os/-/blob/main/SECURITY.md>.

**Do not open a public issue for a security bug.** Use
<https://github.com/Gh0s777tt/E-OS/security/advisories/new> or email
`dzierzawskii98.dam@gmail.com`.

If you found something in *this* code that also exists in `eos-control`, say so — that is a live
issue wearing an archived repository's clothes, and it is worth reporting.
